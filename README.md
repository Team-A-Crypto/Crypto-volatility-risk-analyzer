#  Crypto Volatility and Risk Analyzer

Welcome to **Crypto Volatility and Risk Analyzer**, a student development project undertaken as part of the **Infosys Springboard Internship Program**.

This project focuses on analyzing cryptocurrency price fluctuations and assessing market risk using data analytics, statistical modeling, and Machine Learning techniques. The goal is to convert highly volatile crypto market data into meaningful insights that support informed investment decision-making.

##  Abstract

Cryptocurrency markets are highly volatile, making it difficult for investors and learners to accurately assess risk.

The **Crypto Volatility and Risk Analyzer** evaluates historical cryptocurrency price data to measure volatility and assess risk using statistical techniques and predictive modeling. By visualizing volatility trends, generating risk indicators, and forecasting short-term price movements, the system enables users to better understand market instability and make data-driven decisions.

#  Milestone 4 – System Integration & Advanced Features

###  Objective
To transform the analytical model into a complete crypto risk analytics platform with forecasting and interactive capabilities.

###  Covered in This Milestone

#### 🔹 Frontend & Integration
- Streamlit-based interactive dashboard  
- Real-time data handling  
- Deployment-ready structure  

#### 🔹 Portfolio Allocation & Risk Simulation
- Dynamic multi-coin portfolio allocation  
- Percentage-based weighting system  
- Portfolio-level volatility computation  
- Investment risk scenario simulation  

#### 🔹 Forecasting & Volatility Modeling
- 7-day price forecasting using Machine Learning (Linear Regression)  
- Train/Test split for realistic model evaluation  
- Rolling volatility (7-day & 30-day)  

#### 🔹 Performance Metrics
- R² (Coefficient of Determination)  
- RMSE (Root Mean Squared Error)  
- MAPE (Mean Absolute Percentage Error)  

#### 🔹 Interactive Visualization
- Plotly-based dynamic dashboards  
- Volatility trend visualization  
- Risk classification outputs

#  Project Outcome

The Crypto Volatility and Risk Analyzer evolved from a conceptual volatility analysis model (Milestone 1) into a fully integrated cryptocurrency risk intelligence platform (Milestone 4).

The final system provides:

✔ Real-time cryptocurrency price tracking  
✔ Volatility modeling (7-day & 30-day)  
✔ Risk classification and alerts  
✔ Portfolio allocation analysis  
✔ Machine Learning-based forecasting  
✔ Interactive dashboards  

This project demonstrates the practical integration of data analytics, statistical modeling, and Machine Learning in financial risk intelligence systems.
